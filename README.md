# Fight Performance Studio

Uma plataforma moderna e interativa de marketing digital para um estúdio de luta e performance. O projeto apresenta informações sobre serviços, autoridades da empresa, processos de treinamento e uma experiência de usuário imersiva.

## 📋 Descrição

O **Fight Performance Studio** é um website desenvolvido com React, TypeScript e Vite que oferece uma experiência visual moderna e responsiva. A plataforma destaca:

- **Seção Hero** com mensagem impactante
- **Apresentação de Autoridades** do estúdio
- **Destaques dos Serviços** (Features)
- **Processo de Treinamento** detalhado
- **Informações de Audiência** alvo
- **Integração WhatsApp** para contato rápido
- **Design Responsivo** para todos os dispositivos

## 🛠️ Tecnologias

- **React 19** - Biblioteca UI
- **TypeScript** - Tipagem estática
- **Vite** - Build tool e dev server
- **Tailwind CSS** - Estilos responsivos
- **Lucide React** - Ícones

## 🚀 Começar

### Pré-requisitos

- Node.js (versão 16+)
- npm ou yarn

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/felipebetoni/fight-performance-studio.git
   cd fight-performance-studio
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra [http://localhost:5173](http://localhost:5173) no seu navegador

## 📦 Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build para produção
- `npm run preview` - Visualiza a build de produção localmente

```

├── components/
│   ├── Header.tsx        # Cabeçalho e navegação

│   ├── Features.tsx      # Destaques dos serviços

│   ├── Audience.tsx      # Informações da audiência

│   ├── StickyWhatsApp.tsx # Widget WhatsApp flutuante
│   └── ui/

├── App.tsx               # Componente raiz
├── constants.ts          # Constantes da aplicação

```
